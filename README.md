### 🏗️ What I'm Building

**Polygrow** — AI-native business OS for solopreneurs. My flagship; in active development.

**Rustenwer** — intelligence fabrication: the cheapest *sufficient* intelligence for any problem. LoRA training infra + LangGraph agents.

**Rogis** — Redis, reimagined for AI agents: deterministic core + native semantic engine (HNSW vectors).

**Domino RL** — teaching AI to play Cuban double-9 domino with pure RL. Zero heuristics, sparse rewards, MAPPO self-play.

**Agentropy** — observability for AI agents. *See it. Improve it.* (open-core)

**DeepBooks** — immersive reading: real books, AI-generated *momentos*, ambient experiences.
